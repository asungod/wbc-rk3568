边缘计算 · 显微图像分析

RK3568 白细胞端侧分析

通过检测与分类双模型组织显微图像处理流程，在端侧完成候选细胞定位、区域裁剪、五分类结果解析与置信度判断，并为待复核样本提供远程上传入口。

两阶段推理

检测模块定位候选细胞，分类模块处理裁剪区域。通过 RKNN-Toolkit Lite2 接入 RK3568 NPU。

本地交互

提供摄像头预览、图片输入、拍照分析、结果保存及 Qt 操作界面。

按需上传

依据分类置信度标记待复核样本，通过 HTTP(S) 传输原始图片与结构化结果。

图像输入 → 640×640 检测 → 筛选与裁剪 → 224×224 分类 → 本地结果与按需上传

代码内容

公开模块包括图像预处理、RKNN 推理封装、YOLOv5 后处理、分类解析、结果存储、上传客户端和 Qt 界面。模型文件另行配置，类别索引及输出形式与导出模型保持一致。
